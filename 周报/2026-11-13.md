### ConfigCenter 2.1.7 — 公网地址后缀模式、统一入口端口与 IoTDB 共享组

完成 2.1.7 需求定稿、服务端与 SDK 实现、四种部署方式适配及配套文档。当前处于本地开发与验证完成阶段，尚未推送、发布 SDK 或部署集群。

**其他进展**

- 后缀模式服务端实现：新增 `isSuffixMode` 布尔开关，按 `Domain` → `GlobalIP` 拼接统一域名 + URI 路径生成 `publicAddress`；路径缺失时静默返回空，不影响注册与查询（`4336935`）
- 新增 `iotedge-iotdb` 共享组，`IoTEdge` / `IoTEdge-Worker` 共享 IoTDB 资源，四份部署配置同步（`ca3b809`）
- 统一后缀入口端口为 `suffixPort`：0 表示按 `isSSL` 使用 80/443，非零为实际端口；旧双端口配置迁移为单端口（`86249c3`）
- SDK 新增 `Router.uriPrefix` 字段与 `is_suffix_mode` / `is_ssl` / `suffix_port` 公共配置键，统一为 `module.SuffixPort`（`2970721`、`f865efd`）
- 新增 2.1.7 PRD（`prds/prd.md`）与实现记录（`specs/003-public-address-mode/implementation.md`）
- 输出《DP 环境 DNS、Traefik 与请求转发》网络分析，梳理 DNS → 节点 NAT → Traefik → Pod 全链路
- 输出《公网地址后缀模式与 Go-SDK 接入指南》，供第三方 SDK 接入
- 兼容性：旧配置未提供新参数时保持前缀模式；手动公网地址优先级不变
